# Nori – Project Modelling

Nori is the modelling tool in the RAMEN Suite. Use it to define project-specific node types, properties, relationships, and annotation shapes before recording editorial data. For example, a correspondence edition can define `Letter` as a refinement of `Collection` and specify which types of text and annotations it allows.

The [specification](/specification) describes the RAMEN Core model and exchange formats. See [Project-Specific Refinement](/concepts#project-specific-refinement) for the modelling concepts.
