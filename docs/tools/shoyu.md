# Shoyu – Graph-Based Publication

Shoyu is the publication tool in the RAMEN Suite. It presents editorial content together with its annotations, entities, and connections so readers can explore an edition.

The [concept guides](/concepts) explain the underlying model. Tool-specific setup and configuration belong in the [RAMEN Suite repositories](https://github.com/RAMEN-Suite).
