# Miso – Content Editor

Miso is the content and annotation tool in the RAMEN Suite. It is used to capture text and image sources, annotate passages and regions, and link annotations to entities such as people and places.

The project model defines which content properties, annotation types, and connections are available. See [Capturing Content](/concepts/content) for the modelling patterns and the [RAMEN Suite repositories](https://github.com/RAMEN-Suite) for tool-specific setup information.
