# Specification

The specification defines the shared RAMEN types, their relationships, and the file formats used to exchange models and data. A project model builds on these definitions and specifies its own types, properties, and validation rules.

## Find what you need

| Topic                                             | What you will find                                                                      |
| ------------------------------------------------- | --------------------------------------------------------------------------------------- |
| [Reference model](/specification/reference-model) | Base node types, inherited properties, relationships, and project-specific refinements. |
| [JSON schemas](/specification/json-schemas)       | Help choosing a schema, download links, and file formats.                               |
| [Validation](/specification/validation)           | Checks for document structure, property values, and allowed connections.                |

For an introduction with illustrations, start with [What is RAMEN?](/concepts). To create a model visually, use [Nori](/tools/nori).

## Using RAMEN Core

The npm package [`@ramen-suite/core`](https://www.npmjs.com/package/@ramen-suite/core) implements the reference model and the RAMEN Model Format (RMF). It includes the schemas published here and APIs for creating, exchanging, and validating models.

```sh
npm install @ramen-suite/core
```

The [RAMEN Core guides](https://ramen-suite.github.io/ramen-core/) explain how to use these APIs in your application.
