# Examples

The concept guides contain worked modelling examples. They illustrate choices a project can make when organising its material and recording editorial statements.

| Example                                                                    | What it shows                                           |
| -------------------------------------------------------------------------- | ------------------------------------------------------- |
| [Correspondence](/concepts/context#correspondence)                         | Letters, witnesses, transcriptions, and nested corpora. |
| [Regesta](/concepts/context#regesta)                                       | Separate texts grouped into one entry and volume.       |
| [Books of fortune](/concepts/context#books-of-fortune)                     | Sections organised by witness and by reading path.      |
| [Text and image annotations](/concepts/content#annotating-text-and-images) | Selectors for passages and image regions.               |
| [TEI/XML mapping](/concepts/content#using-teixml-and-ramen)                | Mapping selected markup to annotations and entities.    |
| [Statements about entities](/concepts/knowledge#statements-and-references) | A relationship recorded through an annotation.          |

Use [Nori](/tools/nori) to define a project model visually. The [Core correspondence example](https://ramen-suite.github.io/ramen-core/guides/examples/correspondence-edition.html) shows model creation through the API.
