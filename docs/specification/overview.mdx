# Specification

RAMEN Core implements the RAMEN reference model and the RAMEN Model Format (RMF). The [npm package `@ramen-suite/core`](https://www.npmjs.com/package/@ramen-suite/core) includes the modelling API and the JSON schemas published on this page. The [Core guides](https://ramen-suite.github.io/ramen-core/) cover model creation, exchange, and validation.

```sh
npm install @ramen-suite/core
```

## Reference model

The <a href={specification.referenceModel}>RAMEN reference model</a> defines the four base node types and their relationships. RAMEN Core exports it as `RAMEN_MODEL` from `@ramen-suite/core/ramen`. A RAMEN project starts from this model and declares the types, relationships, and annotation shapes it uses.

## JSON schemas

These files ship with <code>@ramen-suite/core@{specification.coreVersion}</code>. Each link resolves to the canonical URL declared in the schema's `$id`. The same files are available locally at `@ramen-suite/core/schemas/<filename>`.

Use a **model schema** for a single model level. Use a **file schema** to exchange a model together with its predecessors and their declarations. Use the **instance graph schema** for recorded nodes and relationships. The **annotation definitions schema** describes the annotation shapes declared by a project.

JSON Schema checks the document structure. RAMEN Core also resolves references and checks recorded data against the project model, including allowed relationships, cardinalities, and annotation shapes.

The Core package, document formats, and RAMEN reference model have independent versions. See the [JSON Schemas guide](https://ramen-suite.github.io/ramen-core/guides/schemas.html) for the format and package conventions.
